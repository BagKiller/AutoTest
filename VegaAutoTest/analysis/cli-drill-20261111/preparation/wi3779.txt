# WI 3779 rev=9 state=AVAILABLE
TITLE: 【边缘检测】Vega100 加装 Edge Detector 后，边缘对位数据源支持 EdgeDetector/DarkField 配置切换

## Description
需求描述： 部分 Vega100 机型进行硬件改造：加装 Edge Detector（纯被动边缘信号接收器）与第二张同型号 NI 采集卡。改造后边缘对位（找槽）所需数据可来源于 Edge Detector（新）或某一暗场通道（现状，保留），由机器配置切换；未改造的 Vega100 行为零变化，V200/V300/V500 零变化。 1. 来源配置：Edge Detection 配置组新增“边缘数据来源”条目（下拉 DarkField/EdgeDetector，缺省 DarkField），仅加装 Edge Detector 的机型可见可选——未加装机型无此条目，从结构上杜绝“无硬件却选了 EdgeDetector”的非法状态； 2. 两条对位路径均支持 Edge Detector 来源：Inline（主扫内联）与 Dedicated（固定光学预扫，系统配方 202）——区别只在数据来源，运动/几何/光学流程骨架不变； 3. 装机向导激光类型页新增 Edge Detector 选项，与激光族（PIC/Coherent）选择组合确定机型变体；现场不重装的切换走配置编辑器的 Hardware Profile 下拉； 4. 加装机型以 EdgeDetector 为源时，第二张采集卡仅采集边缘窗口数据，不得出现整盘数据缓存积压； 5. 默认行为零变化：默认变体 + 默认来源 DarkField 下与现状一致；诊断/离线边缘数据文件不加来源标记。  验收标准： 1.【V100 基线回归】默认 profile（Vega100-PIC）Sim 跑晶圆检测流程：行为与当前版本一致；诊断页（ComponentManager）无 DAQDevice_2 设备实例； 2.【V100+ED·Inline】用户目录切 -ED profile、边缘数据来源=EdgeDetector、NotchScanMode=Inline：诊断页存在 DAQDevice_2 实例；对位正常完成；运行全程内存平稳，无整盘级缓存积压； 3.【V100+ED·Dedicated】同 profile、NotchScanMode=Dedicated：预扫下发固定光学（配方 202）；对位完成后主扫跳过边缘采集； 4.【V100+ED·回退暗场】同 profile、边缘数据来源=DarkField：行为与基线等价（第二张卡静默不参与）； 5.【V200 回归】Vega200 Sim 常规流程：第二张采集卡行为与当前版本一致； 6.【装机向导】安装器环境：激光类型页 Edge Detector 选项 × 激光族共 4 种组合，安装后机器 profile 落对应 -ED 变体（需安装环境，Sim 内不可测）； 7.【单元测试】边缘来源解析与边缘转发守卫真值表单测通过（开发交付项）。
