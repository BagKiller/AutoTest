TITLE 【表面质量】测量支持按膜系选择，结果按膜分枝保存，AFS 子函数按膜查表
---DESC---
需求描述：
表面质量测量需要区分不同膜系（不同晶圆表面薄膜）下的杂光背景：同一晶圆在不同膜系下的测量结果应分别沉淀、互不覆盖；AFS 子函数执行前的 BPS 光学档位与曝光按所选膜系的标定表下发。
本次范围（膜选项＋AFS 修订）：
1. 测量前可选当前膜系（候选来自 BPS 诊断页的膜系标定表，首项恒为 default）；切换晶圆后膜选择自动回到 default，防止上一晶圆所选膜残留。
2. 测量结果按膜分枝保存；结果页按「晶圆＋膜」两级选择查看；导出文件名带膜名。
3. 斜入射 P/S 组的 AFS 子函数前按所选膜系查 BPS 表下发 OD/曝光（default 膜不查膜表，行为不变）；正入射/C 组不执行子函数，改为相机停靠保护位并清除上一轮 AFS 超时残留。
4. 旧版本保存的结果文件升级后自动并入 default 膜枝，无需人工处理；灵敏度助手 Haze 取值跨膜取最新实测，行为与升级前一致。
验收标准：
1. 配置页选择晶圆后出现「膜」下拉，候选与 BPS 诊断页膜系表一致；膜表加载失败时仅剩 default 可选并有红字提示，default 仍可正常测量。
2. 选不同膜分别测量后，结果页切换膜下拉，各膜的测量列表互不混杂。
3. 运行页摘要带显示「目标膜」与所选项一致。
4. 正入射组运行完成后该组「AFS 超时」列显示为否（即使上一轮显示为是）。
5. 结果导出文件名为「晶圆名_膜名」；所选膜在盘上无已保存数据时导出给出先保存提示。
6. 用升级前的旧结果文件打开结果页，历史数据全部显示在 default 膜下且数值完整。
7. 单元测试全绿（数据/服务/执行层/灵敏度回归）；真机验证项：膜查表下发的 OD/曝光实测、正入射停靠保护位时序。
