TITLE 【Recipe】添加SPA后KLARF勾选界面新增属性被默认勾选
---DESC---

---REPRO---
【前置条件】：打开 Inspection 的 Recipe 编辑页面，选择一个已启用通道的 Recipe；该 Recipe 已启用 Result Output 元素，并在 Output Options 中勾选 KLARF，且「选择数据」中已有手工勾选项（非默认全选）。
【复现流程】：1. 在 Recipe 元素列表中为同一通道新增一个 SPA 元素（Spatial Analysis），保持默认子参数，确认元素已启用并已选择通道。
2. 打开 Result Output 元素 → Output Options → 勾选 KLARF → 查看「选择数据」区域。
3. 展开对应通道的 Defects 节点，查看新增的 Cluster / Scratch / Slipline 缺陷及其属性（Area、X、Y、Length 等）。
4. 观察这些新增缺陷/属性的勾选状态；也可再切换 SPA 的「聚类/划痕」或「滑线」子参数后重复观察。
【预期结果】：新增的缺陷/属性只出现在选择数据列表中，默认不勾选；原有勾选状态保持不变。
【实际结果】：新增的缺陷/属性被自动默认勾选（X/Y 也随之勾选），KLARF 输出范围被意外扩大；需要手动逐项取消。
【版本】：最新开发版
